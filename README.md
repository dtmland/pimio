# pimio

[![CI](https://github.com/dtmland/pimio/actions/workflows/ci.yml/badge.svg)](https://github.com/dtmland/pimio/actions/workflows/ci.yml)

A local-first photo and video organizer for repairing and maintaining
chronological media libraries. Built with C++20, Qt 6, and QML.

## Building

Requires CMake >= 3.24, Ninja, a C++20 compiler, and Qt 6 (>= 6.4 to build;
6.8.3 is the version verified by CI).

```
cmake --preset default
cmake --build --preset default
ctest --preset default
```

See [docs/conventions.md](docs/conventions.md) for repository layout, naming,
and the additional Linux X11 test run.

## Releasing

Releases are automated from version tags that match `v*` or bare semver tags
like `0.1.1`.

Cut a release by creating and pushing a tag:

```
git tag 0.1.1
git push origin 0.1.1
```

Pushing the tag runs `.github/workflows/release.yml`, which creates a GitHub
pre-release tied to that tag with autogenerated release notes. GitHub's default
source archives remain available, and the workflow also uploads generated
release assets:

- `pimio-<tag>-source-snapshot.tar.gz`
- `pimio-<tag>-Linux-binaries.tar.gz`
- `pimio-<tag>-Windows-binaries.zip`
- `pimio-<tag>-macOS-binaries.tar.gz`
